# Roadmap

Validation-first. Features after evidence.

## 1. Validate problem

- Teacher interviews at Quantum STEM (informatics first)
- Confirm homework / exam-prep pain points
- Confirm what materials can be approved for AI use

**Done when:** written problem notes + at least one teacher engaged.

## 2. Validate RAG / LLM quality

- Ingest one approved material
- Connect first real LLM
- Build independent 30–50 question eval set
- Measure correctness, source accuracy, usefulness, hallucinations, latency

**Done when:** teacher-reviewed eval summary supports a student trial — or we stop / redesign.

## 3. Teacher pilot

- Teacher reviews answers and sources on the approved topic
- Align academic integrity rules
- Agree stop / continue thresholds

**Done when:** teacher approves limited student access.

## 4. Student pilot

- Small group, school agreement in place
- Collect usefulness + qualitative feedback
- Watch for integrity and privacy issues

**Done when:** pilot review document exists.

## 5. Exam Prep experiment

Only if core Q&A quality and student feedback justify it:

- Flashcards / tests / weak-topic practice prototypes
- Compare engagement vs plain Ask Quantum

**Done when:** go / no-go on Exam Prep as a product line.

## 6. Decide whether to scale

- Expand topics / classes inside Quantum STEM, or pause
- Tutor Mode / Teacher Insights only with clear demand
- Multi-school only after one-school proof

## Version markers

| Version | Meaning |
| --- | --- |
| **v0.1** | Technical retrieval prototype (current) |
| **v0.2** | Real Quantum material + LLM + source-grounded answers |
| **Pilot** | Teacher + students under agreement |
| **Post-pilot** | Exam Prep / Tutor / Insights if results justify |

No production, PMF, or multi-school scale claims until evidence exists.
